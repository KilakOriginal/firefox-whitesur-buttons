This Firefox theme replaces the close/minimise/maximise buttons with macOS Big Sur inspired ones. This is a stripped down version of vinceliuice's [WhiteSur-firefox-theme](https://github.com/vinceliuice/WhiteSur-firefox-theme) for those who want the default look and feel of Firefox without the default title bar buttons.

## Installation
Just import the theme.css file in your userChrome.css (typically `.mozilla/firefox/<PROFILE>/chrome/userChrome.css`, `.librewolf/<PROFILE>/chrome/userChrome.css`, etc.) by adding `@import "<PATH>/CustomTitlebar/theme.css";` to it and set `toolkit.legacyUserProfileCustomizations.stylesheets` to `true` in about:config.
